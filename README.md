# Discord Voice AFK

A simple script that automatically connects your Discord account to a specified voice channel to keep you online 24/7.

## Features
* **One-Click Start:** Launch easily with `start.bat`.
* **24/7 Connectivity:** Keeps your account in the voice channel continuously.
* **Auto-Reconnect:** Automatically rejoins if the connection drops.

## How to Use

### Step 1: Install Node.js
1. Go to the official website: [https://nodejs.org/](https://nodejs.org/)
2. Download and install the **LTS** version.
3. Complete the setup wizard (keep default settings).

### Step 2: Download the Project
1. Download this repository as a `.zip` file or clone it.
2. Extract all files into a folder on your computer.

### Step 3: Install Required Packages
1. Open the project folder.
2. Click on the address bar at the top of the folder, type `cmd`, and press **Enter**.
3. In the command prompt window, type the following command and press **Enter**:
   ```bash
   npm install

### Step 4: Configure Settings
Open config.json with any text editor.
Fill in your details.
Save and close the file.   

### Step 5: Run
Save config.json and double-click start.bat.
